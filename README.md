# AudioToText
## Deployed Link: https://fluent-speakers-guide.netlify.app/
## Steps to follow to setup the project:
## For Server:
### cd server
### npm install
### npm run start
## For Client:
### cd client
### npm install
### npm run dev
## Features :
### User Authentication
### File Upload
### File Storage (using FireBase)
### Audio to Text Transcription using Assembly Ai Api.
### Access to Past Transcripted Texts .
### Database : MONGODB
### Backend Deployed using Render.com
